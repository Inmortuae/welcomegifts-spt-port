# Welcome Gifts for SPT 4.1.6

A community continuation of Welcome Gifts by ShadowXtrex (EFCL) and Senko, maintained by Inmortuae with ShadowXtrex’s permission. See the [original project](https://gitlab.com/ShadowXtrex/welcomegifts).

Version 4.3.0 adds gift quests and SPT-compatible reward substitutions. It targets SPT 4.1.6 and uses WTT CommonLib 3.0.8. The mod loaded successfully in an isolated SPT 4.1.6 server startup test. Fika and in-game claiming are unverified.

The release and Forge listing are pending.
